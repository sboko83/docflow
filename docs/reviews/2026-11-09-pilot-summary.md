Исход — событие `unit_end`, включая `blocked` перед повторным запуском.
Два исхода одного юнита не становятся двумя юнитами. Время складывается
по всем исходам, стоимость — только там, где она записана. Итого в
сохранившихся потоках 27 завершённых юнитов, 31 исход и 13.30 ч; это
часть истории проектов, а не вся работа по их планам. Стоимость известна
для 21/31 исходов, поэтому сравнивать цену юнита между проектами нельзя.

Из 27 событий проверки 25 помечены `reused: true`; ненулевых кодов в
этих событиях нет. Это не доказывает отсутствие ошибок проверки агентом:
его промежуточные попытки в старых потоках не видны. Четыре исхода
`blocked`, три события replan и одно переключение маршрута показывают
восстановление прогона, но без контрольной ветки не измеряют выигрыш цикла.
Отсутствие `route_switch` в старом потоке также не доказывает отсутствие
переключений в работе проекта.

`test_changes` и `unverified` отсутствуют во всех 31 исходах. Rework
достоверно не измерен: в iOS-проекте нужны истории вложенных репо, а
подсчёт по совпавшим файлам смешивает исправления с новой работой.
Отсутствующие поля и проекты без событий не считаются нулями.

## Время и контекст

Для Go CLI к ZIP сопоставлены сохранившиеся локальные `run/*.out` и
`stats/*.json`. Все 18 логов попыток сохранены; 16 имеют формат Pi,
два — Codex без длительностей. Длительности Pi найдены для 14/16 исходов.
Сумма записанных длительностей модели — 2.04 ч
(555/555 ответов), инструментов — 1.59 ч (629/636 результатов).
В 10 исходах длительность есть у каждого наблюдаемого ответа и результата
инструмента. Это покрытие записей, а не доказательство полноты истории.

Длительности — суммы `durationMs` завершённых сообщений. Повтор сообщения
в логе возобновлённой сессии учитывается один раз; сообщения вне временного
окна исхода исключены. Время параллельных инструментов может пересекаться,
поэтому суммы не образуют разбиения стены. `verify` в этих потоках не
содержит длительности, а `reused: true` не измеряет проверку, выполненную
агентом раньше. Время Verify/gate неизвестно и не вычисляется вычитанием
модели и инструментов из общего времени. Для iOS сырых логов и `stats/`
в доступном наборе нет.

У 13/14 уникальных юнитов Go CLI есть сопоставленные proxy и контекст
запросов Pi: `input + cacheRead + cacheWrite`, без вывода модели. Медиана
отношения первого контекста к proxy — 1.09, пикового — 6.74, роста от
первого до пикового — 5.51. Proxy лежит в диапазоне 5400–21156, пик —
45855–169110 токенов. Proxy близок к стартовому контексту этой выборки,
но не предсказывает рост сессии; сумма токенов всех запросов не является
размером одного контекста. Сравнение не переносится на другие модели и
стеки без их логов.

## Воспроизведение

`python3 tools/pilot-summary.py --anonymize work/pilot/<отчёт>/docflow-pilot-data.zip ...`
читает ZIP без распаковки и печатает JSON по проектам. Рядом с каждой
суммой — число измеренных и всех исходов. Одинаковые копии потока
учитываются один раз; разные копии с тем же проектом и именем потока
останавливают сводку, чтобы не смешивать снимки. Метки `project-N` скрывают
имена, но не обезличивают сами числовые данные.

`--logs '<проект>=<git-dir>/docflow'` подключает локальные `run/` и `stats/`
для проекта с тем же именем, что в ZIP; флаг можно повторять. Без него
длительности модели и инструментов и сравнение контекста остаются
неизвестными. Вывод содержит только числовые метрики и идентификаторы
юнитов, без промптов, команд инструментов и локальных путей. У каждого
исхода видны покрытие логов и число сообщений с длительностью; сравнение
контекста считает уникальные юниты. Запись `stats` с датой вне наблюдаемых
окон юнита не используется, чтобы не подмешать более поздний прогон.
