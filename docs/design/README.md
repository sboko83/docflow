# bsv-docflow — проектные решения

Цикл как у OpenSpec (`changes/<id>/` → выполнение → `archive/`), без
инструмента: минимальная система под свои проекты и скриптовую автоматизацию.
Роль architecture; читать тему по ссылке из `Read:` юнита.

| Тема | Файл | Содержание |
|---|---|---|
| Формат | [format.md](format.md) | термины, раскладка, `docflow.md`, план, архивная запись, версии формата |
| Архив | [archive.md](archive.md) | журнал решений, отмена, источник правды |
| Цикл | [cycle.md](cycle.md) | шаги юнита, размер, учёт токенов, ветки, коммиты |
| CLI | [cli.md](cli.md) | команды, коды выхода, версия репозитория |
| Ростер | [roster.md](roster.md) | каталог, политика, условия, резолвер, бюджет, миграция; `run`/`lint` ростер не читают |
| Раннер | [runner.md](runner.md) | `docflow run`: цикл, лимиты, таймаут, интерактивный API |
| Терминальное приложение | [tui.md](tui.md) | `docflow tui`: четыре экрана, ростер, поток, история, Backlog, пауза, восстановление, сигналы, lock |
| Скиллы | [skills.md](skills.md) | граница с bsv-docs, скиллы, установка, самоприменение |
| Эталонный бенчмарк | [bench.md](bench.md) | корпус задач, проверка, ветки прогона и формат результатов |

Справочник раннера (ключи профиля, плейсхолдеры) — [../usage.md](../usage.md#автозапуск).
