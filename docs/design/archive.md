# Архив и источник правды

## Архив

- Архив — журнал решений (ADR-подобный), записи не переписываются.
  Единственная допустимая правка — `superseded_by: Pxxx` во frontmatter.
- Частичная отмена (отменено одно решение записи, остальные действуют):
  старая запись не правится и `superseded_by` не получает — иначе он
  объявит устаревшими и действующие решения. Связь пишет новая запись в
  своём `## Decisions`: «Заменяет решение X из [Pxxx](Pxxx-name.md)».
  Пример — P007 к P006. Ключ `supersedes` в новой записи с обратными
  ссылками от `docflow` — отложен до второго такого случая.
- Почему — [P010](../archive/P010-design-rationale.md).
- План после архивации удаляется: полная версия остаётся в git. ARCHITECTURE
  и другие планы ссылаются только на `archive/`; `close` отказывает, пока на
  удаляемый план есть ссылки.
- Решение без плана (мелкая правка, которая что-то решила) — `docflow note`,
  запись в архиве в той же нумерации. У «почему» остаётся одно место.

## Источник правды

- Статус юнита — только в плане. `docflow.md` хранит только порядок планов.
- Текущий юнит вычисляется: юнит `[~]`, иначе первый `[ ]` с выполненными
  `Depends` в первом плане очереди, где остались `[ ]` или `[!]`
  ([P001](../archive/P001-docflow-cli.md)). `[!]` останавливает выдачу
  (код 3). План, где все юниты `[x]`/`[-]`, ждёт `close`; `status` пишет
  `ready to close` ([P003](../archive/P003-cli-fixes.md)), выдача идёт дальше
  по очереди.
- План меняет скрипт (`prompt`, `done`, `block`), не агент правкой текста:
  агент ломает формат, скрипт — нет.
