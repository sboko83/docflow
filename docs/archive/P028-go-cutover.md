## Outcome

`docflow` — только Go-бинарник: Python-CLI и его тесты удалены,
`tools/install.sh` собирает `bin/docflow` и ставит скиллы найденным агентам.
Раннер: `timeout = 0` — без таймаута; квота прерванного вызова и перезапуск
после `migrate` покрыты тестами. `docflow stats` показывает `base_ctx` и
`grow/proxy`. Не проверены: рантайм Windows (только кросс-сборка) и
`base_ctx` юнита с интерактивным окном и сессией раннера одновременно.

## Decisions

- Срез — автономно под Go-раннером, а не интерактивно, как решал P024 —
  Go-раннер вызывает шаги через `os.Executable()`, замена `bin/docflow` его не
  задевает — отвергнуто: интерактивный срез.
- Ревью — юнит другого ассистента (Claude) в конце каждой фазы по коммитам с
  префиксом фазы; дефект — `blocked` + `blocker: plan` и replan, мелочь —
  `unverified`, ревьюер не правит — ревью нашло два дефекта (устаревшие
  инструкции, красный parity после смены формата stats) — отвергнуто: ревью
  после каждого юнита (вдвое больше вызовов при тех же находках).
- `tools/install.sh` ставит скиллы только агентам, чей CLI есть в PATH
  (`claude`, `codex`, `pi`), и в `~/.zcode/skills` при наличии `~/.zcode`;
  `--no-skills` отключает — отвергнуто: всегда все агенты (создаёт каталоги
  агентам, которых нет на машине).
- `base_ctx` — контекст первого запроса первой сессии юнита (среда и промпт
  до чтения файлов), `grow/proxy = (peak − base) / proxy` — отвергнуто:
  вычитать медиану первого запроса по плану (смешивает агентов с разной
  средой).
- Порядок окон интерактивных транскриптов задан порядком путей — `base_ctx`
  воспроизводим — отвергнуто: обход map.

## Gotchas

- `bin/docflow` — собираемый артефакт вне git, на него указывает
  `~/.local/bin/docflow`. После правки Go-кода — `go build -o bin/docflow
  ./cmd/docflow` (или `bash tools/install.sh`), иначе `docflow` в PATH старый.
- Parity-сценарии (`tools/parity/scenarios/`) сверяют точный вывод CLI:
  смена формата вывода требует правки сценария, а `Verify:` такого юнита
  должен гонять `bash tools/parity/run.sh bin/docflow bin/docflow`. Упавший
  сценарий останавливает весь набор.
- `bash tools/parity/run.sh bin/docflow` с одним аргументом пересобирает
  `bin/docflow-go`.
- Поиск устаревших упоминаний — без учёта регистра (`grep -i`): `python`
  пропускает `Python`.
