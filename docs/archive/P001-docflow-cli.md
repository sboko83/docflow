## Outcome           <!-- 2–3 строки: что теперь есть -->
`bin/docflow` (Python 3.11+, stdlib, один файл) реализует формат и все
команды из docs/design/: чтение и `lint`, цикл юнита с отпечатком дерева,
жизненный цикл плана, `migrate`, `install-skills`. Покрыт тестами `tests/`.

## Decisions         <!-- решение — почему — отвергнутая альтернатива -->
- Строка с отступом под пунктом `- ` продолжает пункт (и значение поля без
  пунктов) — так переносятся пункты в планах — отвергнуто: поле кончается
  на первой строке без `- `.
- Значение в строке ключа продолжают следующие строки и без отступа — до
  `Key:`, `- `, пустой строки или заголовка — так уже написаны `Traps:` —
  отвергнуто: требовать отступ и править планы под парсер.
- Неизвестный ключ frontmatter и текст юнита вне полей — предупреждения —
  разбор они не ломают — отвергнуто: ошибка, блокирующая цикл из-за
  заметки.
- Файлы `## Context` проверяются как `Read:` и входят в бюджет каждого
  юнита — их читает каждый юнит — отвергнуто: считать только текст секции.
- Юниты `[x]`/`[-]` по `Read:` и бюджету не проверяются — это история,
  файлы переезжают — отвергнуто: проверять все и ломать `lint` после
  переездов.
- Циклы в `Depends` исключены запретом ссылок вперёд — проще поиска
  циклов — отвергнуто: отдельный поиск циклов.
- План для выдачи — первый в очереди, где остался `[ ]` или `[!]` — иначе
  `[!]` последнего юнита пропускался бы — отвергнуто: «где остались `[ ]`».
- `prompt` проверяет чистоту дерева только при `[ ]` → `[~]` — повторный
  `prompt` видит свою же незаконченную работу — отвергнуто: проверка
  всегда, перезапуск после сбоя требовал бы stash.
- Отпечаток `verify` снимается после команды — закоммичено дерево, каким
  его видел `Verify` — отвергнуто: снимок до запуска, побочные файлы
  ломали бы сверку.
- `done` требует `[~]` — иначе обход проверки чистоты в `prompt` —
  отвергнуто: разрешать `[ ]`.
- `install-skills` не ищет корень docflow-проекта — ставит скиллы своего
  репозитория — отвергнуто: требовать docflow-проект в cwd.

## Gotchas           <!-- ловушки, актуальные после закрытия -->
- Совместимость с Python 3.11 проверена только
  `ast.parse(..., feature_version=(3, 11))`: запуска на 3.11 не было.
- `close` падает traceback'ом, если нет `docs/archive/`: git не хранит
  пустой каталог, созданный `init`.
- `lint` не знает ключ `superseded_by` архивной записи: предупреждение
  unknown frontmatter key.
- На этой машине скиллы — каталоги Ruleblend: `install-skills` без
  `--target` откажет с кодом 2, так и задумано.
- `commit` делает `git add -A` по всему репозиторию: мусор отсекает только
  `.gitignore`.

## Follow-ups        <!-- что ушло в Backlog -->

- `lint` принимает `superseded_by` во frontmatter архивной записи.
