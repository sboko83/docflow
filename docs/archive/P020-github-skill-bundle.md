## Outcome
Из одного checkout устанавливаются CLI и пять согласованных скиллов для
Claude Code и Codex без обязательного Ruleblend. Поставка подготовлена,
но не опубликована; внешняя приёмка остаётся в Follow-ups.

## Decisions
- Пять отдельных скиллов в одном репозитории — процесс получает все зависимости
  из одного источника, общие правила документации и changelog применимы отдельно —
  отвергнуто объединение в один большой скилл.
- Префикс `bsv` у проекта и скиллов, короткая команда `docflow` — различимость
  публичного проекта без удлинения ежедневных команд — отвергнуты удаление
  префикса и обязательная команда `bsv-docflow`.
- GitHub выбран будущим источником релизов; Ruleblend импортирует те же исходники
  и остаётся необязательным — отвергнуты отдельные локальные и публичные версии.
- Явный `--agent claude|codex` с default `claude` и отдельными каталогами агентов —
  совместимость действующих установок и соответствие правилам обнаружения —
  отвергнуты автоматический выбор по PATH и общие каталоги обоих агентов.
- CLI ставится абсолютным симлинком в сохраняемый checkout, ресурсы берутся из
  того же тега; копии скиллов обновляются явно — отвергнуты копирование одного
  CLI без ресурсов, сетевой установщик и автоматический pull при запуске.

## Gotchas
- Checkout нельзя удалять или переносить, пока на него указывают симлинки CLI
  и личных скиллов. Чужая установка и другой checkout считаются конфликтом.
- Проектная копия определяется по `name:` и при обновлении заменяется целиком;
  локальные правки нужно сохранить заранее. Каталоги личной и проектной
  установки имеют разные правила приоритета; в Codex возможны дубли имён.
- `doctor` сравнивает файлы, а не обнаружение скиллов агентом. Отсутствующий
  скилл не меняет код выхода сам по себе — контракт в
  [CLI](../design/cli.md#скрипт-docflow).
- URL GitHub, лицензия и релизный тег не выбраны. Плейсхолдер в инструкции
  не является адресом опубликованного релиза; публикация требует отдельного поручения.
- Ruleblend читает committed HEAD; библиотечный id исходника `bsv-docs` остаётся
  `bsv-docs-2`. Реальная установка не входила в объём плана.
