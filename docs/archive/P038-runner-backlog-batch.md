## Outcome

`install-skills` перенаправляет ссылки навыков, ведущие в `~/.docflow/`, так
что `tools/install-dev.sh` переключает навыки поверх релизной установки.
Раннер передаёт при смене маршрута diff stat и последние сообщения прежнего
агента, юнит ревью получает `## Phase diff`, прогон пишет
`<run-id>.events.jsonl`, `docflow run --close` закрывает готовый план через
агента. Тест таймаута с detached-внуком идёт ~4 с вместо 61 с. Не проверено:
`run --close` с живым агентом — только на fake-агенте.

## Decisions

- `run --close` идёт по цепочке `cheap:`, без неё — `executor:` +
  `fallback:` — закрытие — работа с документацией — отвергнута цепочка
  `acceptance:` как лишне дорогая.
- Убийство detached-внука по таймауту проверяет тест `CallAgent` в
  `internal/agentio`, runner-тест — только таймаут и возобновление —
  agent config не может переопределить `timeout` плана с маршрутом
  исполнителя — отвергнут короткий `timeout:` плана: формат требует ≥ 60.
- База `## Phase diff` — родитель старейшего коммита с буквальным префиксом
  subject `<plan>.<phase>.`, коммит самого юнита ревью исключается по ID —
  соседние номера фаз и коммиты replan не попадают — отвергнут
  `git log --grep`.
- `repos:` передаются в общий рендерер prompt — обычный prompt, раннер и
  read-budget lint строят одинаковый phase diff — отвергнуты отдельные
  реализации.
- Пункт «подписка вместо `$` в итоге прогона» снят при планировании —
  текущего вывода стоимости достаточно.

## Gotchas

- Новые прямые вызовы `cycle.PromptText` обязаны передавать вложенные
  репозитории из `docs/docflow.md`, иначе review prompt и оценка read budget
  разойдутся.
- `## Previous attempt` при смене маршрута снимает git-состояние только
  корневого репозитория, вложенные `repos:` не учитываются.
- `run --close` требует чистое дерево; агенту закрытия нужен `docflow` в
  `PATH` — раннер добавляет туда каталог своего бинаря.
- Signal-тесты (`internal/agentio`, `internal/runner`) внутри песочницы
  Codex на macOS видят выживших detached-потомков; полный verify гонять вне
  песочницы.
- `tools/test-install.sh` пересобирает gitignored `bin/docflow` в рабочей
  копии и переключает ссылки навыков временного `HOME` на checkout.
- Гейт по-прежнему ~3 мин: `internal/runner` ~184 с, самый долгий —
  `TestReplanRun` ~25 с.
