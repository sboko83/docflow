## Outcome
`docflow finish` — `verify`, `done`, `commit` одним вызовом; `status`
печатает стартовое чтение и итог `lint`; `start_read`/`start_budget` с
ошибкой `lint`; Gotchas архива в промпте юнита; `docflow stats` — расход
юнитов по транскриптам Claude. `design.md` разбит на `docs/design/` с
индексом; скиллы укрупняют юниты и проводят мелкую задачу без плана.

## Decisions
- Мелкая задача (один юнит) — без плана, с согласия пользователя; решение —
  `docflow note` — коммит и note уже покрывают случай, новая сущность
  требует формата, шаблона, `lint` и миграции — отвергнуто: сущность
  «task» в `docs/docflow.md`.
- План, все юниты которого вместе укладываются в ~100k контекста, — один
  юнит — 8 планов дали ~35 юнитов по 1–3 минуты в ~7 сессиях: нарезка
  оплачивалась без выгоды свежей сессии — отвергнуто: прежняя нижняя
  граница «объединять мелкие».
- `docs/design.md` → `docs/design/`: индекс + файл на тему, справочник
  раннера — в `docs/usage.md`; стартовое чтение — индекс; превышение
  `start_budget` — ошибка `lint` — 31KB читались в каждой сессии и росли,
  предупреждение никого не останавливает — отвергнуто: только ужать текст;
  один файл с бюджетом.
- `docflow finish` — экономит ~2 запроса на юнит; `verify` остаётся для
  промежуточных прогонов — отвергнуто: слить `verify` в `done` (раннеру
  нужны отдельные шаги для повторов).
- Итог `lint` — строкой в `status`, не отказом `prompt`/`done` — отказ
  посреди юнита из-за формата плана блокирует работу — отвергнуто: `lint`
  внутри каждой команды.
- Gotchas в промпт — из записей архива, на которые ссылаются `## Context`,
  `## Decisions` плана и диапазоны `Read:`, кроме `superseded_by` — ссылка
  уже помечает связь — отвергнуто: теги в Gotchas; все Gotchas в каждый
  промпт.
- Учёт токенов: `prompt` пишет прокси, раннер — id сессий и сумму
  `tokens`, `stats` считает расход по транскриптам Claude; запросы сессий
  раннера в интерактивное окно не попадают — основная работа интерактивна,
  раннер её не видит — отвергнуто: учёт только в раннере.
- «Почему» без записи архива из прежнего `design.md` — одной записью
  [P010](P010-design-rationale.md) — отвергнуто: оставить обоснования в
  темах design.

## Gotchas
- `docflow stats`: `peak_ctx` включает постоянную часть среды (системный
  промпт и схемы инструментов, в Claude Code ~60–65k), а прокси — только
  промпт и `Read:`; `peak/proxy` поэтому завышен.
- `docflow run`, чей юнит правит `bin/docflow`, крутит цикл на коде,
  загруженном при старте; новый код получают только подпроцессы
  `prompt/verify/done/commit`.
- Формат транскриптов — внутренний у Claude Code: строки, которые не
  разбираются, `stats` пропускает молча, смена формата даёт `-`.
- `commit`/`finish` берут `git add -A`: артефакт без строки в `.gitignore`
  (`__pycache__`) уходит в коммит юнита.
- Новая команда CLI — ещё и в списке `test_commands_match_design`
  (`tests/test_parse.py`), по порядку `COMMANDS`.
- `AGENTS.md` этого репозитория — регион Ruleblend: ручная правка требует
  `accept_local_change` до следующего `install`.
