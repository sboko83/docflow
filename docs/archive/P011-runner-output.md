## Outcome
`docflow run` показывает план и юниты с названиями, время начала и конца,
спиннер на TTY, токены и квоту подписки 5h/7d из stream-json `claude -p`;
`-v/--verbose` — детали по юниту. Сигналы терминала останавливают агента
вместе с раннером; мягкая остановка — `s` + Enter или `docflow run --stop`.

## Decisions
- Квота — из `rate_limit_event` в `claude -p --output-format stream-json`
  — единственный машиночитаемый источник в `claude -p`, проверено на
  2.1.287 — отвергнуто: разбор текста `/usage` (только интерактивно,
  формат нестабилен).
- Декодер потока — код, выбранный ключом профиля `stream = "claude"` —
  события (tool_use внутри `message.content`, окна квоты) не ложатся на
  пути `json:a.b`; ассистент без декодера теряет только квоту и действие —
  отвергнуто: мини-язык путей в конфиге.
- Флаг `-v/--verbose` — общепринятое имя — отвергнуто: `--maxinfo`.
- Спиннер и цвета — только на TTY, `NO_COLOR` отключает цвета — вывод
  раннера читают логи и тесты — отвергнуто: всегда.
- Раннер ловит SIGTERM и SIGHUP как Ctrl-C и гасит группу агента —
  агент в своей сессии пережил закрытый терминал, замок с мёртвым pid
  пустил второй раннер, два агента правили один юнит — отвергнуто:
  агент в группе раннера (Ctrl-C прибил бы его без очистки и записи
  лога).
- Мягкая остановка — файл `stop` рядом с замком, ставится строкой `s` +
  Enter или `docflow run --stop`, проверяется между юнитами — строка не
  требует raw-режима терминала, файл доступен из другого терминала;
  случайный Enter не останавливает — отвергнуто: первый Ctrl-C мягкий,
  второй жёсткий (SIGINT получают и дочерние `verify`).
- Итоговая строка `run:` — только если план уже выбран — без юнита
  сводка пуста — отвергнуто: печатать и при `nothing to do`.

## Gotchas
- Раннер исполняет код `bin/docflow`, загруженный при старте: юнит,
  меняющий раннер, виден только со следующего `docflow run`.
- `claude -p --output-format stream-json` без `--verbose` падает.
- Квота — на весь аккаунт: параллельные сессии двигают проценты, дельта
  за юнит — не только его расход. `utilization` — доля (0.08 = 8 %).
- Тесты загружают `bin/docflow` без записи байткода: `bin/__pycache__`
  когда-то попал в git до `.gitignore`, а `.gitignore` уже отслеживаемый
  файл не исключает.
- Спиннер на реальном TTY проверен только фейковым потоком; ввод `s` +
  Enter — тестом через pty.
