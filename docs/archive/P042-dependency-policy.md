## Outcome

Сторонние Go-библиотеки разрешены: правило «standard library only, no
external dependencies» заменено на политику «библиотека — осознанное
решение, инвариант — самодостаточный бинарник». Правило поправлено в
`AGENTS.md`, дизайн-топике [«Скрипт и версия»](../design/cli.md) и README.

## Decisions

- Разрешены сторонние Go-библиотеки там, где stdlib не покрывает нужду;
  каждая — осознанное решение, потому что зависимость остаётся постоянным
  обслуживанием в сессиях агентов (обновления, резолюции версий, новые API)
  — отвергнуто сохранение абсолютного запрета: он возник из формулировки
  задачи «ноль зависимостей», которую поняли буквально, а замысел был
  «пользователю нечего ставить отдельно»; для этого достаточно одного
  статического бинарника, который Go собирает и с зависимостями.
- Инвариант политики — самодостаточная установка: пользователь ставит
  только релизный артефакт (`install.sh`), никаких рантаймов, плагинов
  и отдельно устанавливаемых частей; CGO не включать.
- Дописанный под запретом код остаётся: свой парсер формата в
  `internal/format` и lint работают и покрыты тестами; переписывать на
  библиотеку без конкретной нужды — платить второй раз за оплаченное.

## Gotchas

- Пользовательский README утверждал «standard library only» как
  пользовательское свойство; на деле пользовательское свойство —
  самодостаточный бинарник. Формулировки в README заменены.

  решением в момент появления.
