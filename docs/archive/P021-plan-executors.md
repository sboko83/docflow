## Outcome
План задаёт исполнителей без внешнего конфига; P020 переведён на этот формат
и остаётся frozen. Ошибки назначений, включая дубли, останавливают preflight.
Живые проверки, Python 3.11 и миграция работающего раннера — в Follow-ups.

## Decisions
- Полная тройка исполнителя хранится в шапке и переопределяется юнитом целиком —
  обычный run воспроизводит выбор пользователя — отвергнуты внешний TOML,
  частичное наследование и автоматический выбор модели скиллом.
- Хотя бы одно назначение включает режим для всего плана — незавершённые
  юниты не смешивают Executor и legacy Model — отвергнуто определение режима
  по дате или версии создания плана.
- Назначения используют только встроенные адаптеры; флаги смены исполнителя
  запрещены — окружение не меняет согласованный маршрут — отвергнуто наложение
  пользовательского конфига. Legacy сохраняет прежние профили и ярусы.
- Формат 2 и миграция только маркера — старый CLI отвергает новые назначения,
  старые планы сохраняют маршруты — отвергнуты формат 1 и переписывание планов.
- Проверка всех маршрутов draft/frozen доступна только через dry-run —
  приёмка не меняет очередь и статусы — отвергнут обычный run произвольного плана.
- Пустой скелет new остаётся без назначения; скилл записывает выбор пользователя
  и сверяет lint и все маршруты — отвергнута подразумеваемая тройка по ярусу.
- Haiku получает разрешения записи по точным именам `haiku` и
  `claude-haiku-5-5` — полное имя не теряет настройку адаптера — отвергнуто
  сопоставление по подстроке, как и в [P007](P007-auto-permission-mode.md).

## Gotchas
- План с исполнителями не читает пользовательский agents.toml; параметры
  вызова определяют встроенные адаптеры. Изменять исполнителя нужно в плане.
- Lint и dry-run проверяют назначения, но не доступность моделей,
  авторизацию или поддерживаемые провайдером значения усилия.
- После миграции формата перезапустить раннер новым CLI; продолжение уже
  работающего старого процесса остаётся отдельным сценарием проверки.
- Источники скиллов обновлены в репозитории; установленные копии не обновлялись.

  строки quota и разрешения записи Haiku; нужен отдельный расход квоты.
- Применение обновлённых скиллов живым агентом с уже выбранными исполнителями:
  сохранение назначения без повторного выбора и вспомогательного конфига.
- Локальный сценарий смены маркера 1 → 2 у уже работающего старого раннера
  с подставным агентом.
- Полный набор на Python 3.11 через `tools/test-py311.sh` при доступном Docker.
