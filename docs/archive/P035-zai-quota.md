## Outcome

`docflow run` знает квоту подписки z.ai для маршрутов pi с моделью `zai/…`:
печатает `quota: zai 5h NN% · 7d NN%` на старте и с дельтой после юнита,
пропускает исчерпанный маршрут z.ai в цепочке и при отказе `limit` ждёт до
сброса из квоты. Живой зонд API z.ai проверен; строка `quota: zai` в
настоящем прогоне на маршруте z.ai не наблюдалась.

## Decisions

- Квота называется `zai` и привязана к маршрутам pi с моделью `zai/…` —
  квота принадлежит подписке z.ai, а не агенту pi — отвергнут общий ключ
  `pi`: он пометил бы исчерпанным pi на других провайдерах.
- Ключ берётся командой `pi auth print-api-key --provider zai` — pi сам
  разрешает окружение и свой `auth.json` — отвергнуто чтение
  `~/.pi/agent/auth.json` (внутренний формат pi, `PI_CODING_AGENT_DIR`).
- Недокументированный эндпоинт `quota/limit` — другого способа узнать
  остаток без вызова модели нет, им пользуется плагин самого z.ai —
  отвергнут отказ от квоты pi.
- Зонд повторяется после каждого вызова маршрута z.ai — поток pi квоту не
  несёт — отвергнут только стартовый замер: без него нет дельты за юнит и
  исчерпание посреди прогона не видно до отказа.
- Окна различаются по `unit`/`number` — поле `type` уже менялось —
  отвергнут разбор по `type`.
- Зонд держит один бюджет `timeout` на получение ключа и HTTP, команда ключа
  идёт через `CallAgent` — время зонда ограничено одним таймаутом, тот же
  механизм kill, что у зонда Claude — отвергнуты полный таймаут на каждый
  этап (до 2×) и голый `exec.Command`.
- Неположительный `timeout` даёт пустую квоту без запуска pi — без бюджета
  время зонда не ограничено — отвергнута трактовка нуля как «без таймаута».

## Gotchas

- Эндпоинт `quota/limit` недокументирован: формат может смениться без
  предупреждения; при сбое зонда агента просто нет в строке квоты.
- `QuotaWindow.Reset` хранит сырые миллисекунды `nextResetTime` как
  `float64` (nil без поля): `agentio.Epoch` и `numericEpoch` раннера сами
  делят ms, а `number()` указатели не читает — класть `*float64` нельзя.
- Окно без числового `percentage` пропускается целиком (не 0%); метки ровно
  `5h`/`7d` — по ним сравниваются дельты и `sameReset`.
- Если исчерпанных окон нет, `Reset` остаётся nil и отказ `limit` ждёт
  `limit_wait`, а не будущий сброс неисчерпанного окна.
- Тесты зонда z.ai, как и прочие PATH-зависимые тесты зондов, пропускаются
  на Windows.

## Follow-ups

- Увидеть строку `quota: zai` и дельту после юнита в настоящем
  `docflow run` на маршруте `pi | zai/…`; приёмка проверила раннер только
  против локального сервера, живой API — отдельным вызовом
  `agentio.ProbeZaiQuota`.
