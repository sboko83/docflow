title: Quota at run start

## Outcome
`docflow run` печатает строку `quota:` сразу после `run:` — квоту агентов,
на которых маршрутизированы оставшиеся юниты плана. Дельта итоговой строки
и первого юнита считается от этого замера.

## Decisions
- Квоту до первого вызова даёт отдельная команда профиля `quota`, без
  обращения к модели: `claude -p /usage` (текст, $0) и `codex app-server` →
  `account/rateLimits/read` (JSON-RPC) — отвергнуто: короткий платный вызов
  модели ради `rate_limit_event`; OAuth-эндпоинт usage с токеном из Keychain
  (docflow не трогает учётные данные); последний известный замер из логов
  прошлых прогонов и rollout-файлов (устаревает за часы).
- Опрашиваются только агенты оставшихся юнитов (с учётом `--max-units`,
  `--agent`, `--model`), параллельно; сбой или таймаут зонда (30 с) —
  агента нет в строке, прогон идёт дальше.
- Окно считается тем же, если время сброса отличается не больше чем на
  10 минут — `/usage` показывает сброс с точностью до минуты и эта минута
  плавает, а сброшенное окно сдвигает время сброса на часы.

## Gotchas
- Вывод `claude -p /usage` — текст для человека; разбираются строки
  `Current session:` и `Current week (all models):`. Сменится формат —
  строка `quota:` на старте пропадёт без ошибки.
- `claude -p /usage` запускает SessionStart-хуки пользователя (~5 с на
  старте прогона).
