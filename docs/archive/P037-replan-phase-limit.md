title: Лимит replan на фазу
closed: 2026-10-25

## Outcome

`docflow run --replans N` (по умолчанию 3) ограничивает авто-replan на
фазу плана, а не на прогон; 2 replan на юнит остаются.

## Decisions

- Лимит `--replans` считается по фазе юнита (`Pxxx.N` из `Pxxx.N.M`) —
  юнит ревью после фазы по замыслу отвечает `blocker: plan` на каждый
  найденный дефект, и каждый раунд ревью тратит replan; бюджет на прогон
  остановил P035 и P036 на четвёртом replan (P036: 1.3, 2.3, 2.5, затем
  2.7), хотя каждый раунд сходился — отвергнуты повышение умолчания на
  прогон (бюджет не растёт с числом фаз, длинный план снова упрётся) и
  сброс счётчика после выполненного юнита (не ограничивает цикл
  ревью → правка → ревью внутри фазы). Заменяет решение о лимите на прогон
  из [P025](P025-autonomous-run.md).

## Gotchas

- Три раунда ревью одной фазы без схождения — стоп `replan limit reached`;
  это сигнал человеку, а не повод поднимать `--replans`.
