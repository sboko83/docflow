## Outcome           <!-- 2–3 строки: что теперь есть -->
`close`/`note` сами создают `docs/archive/`; `lint` принимает
`superseded_by` в архивной записи; `status` пишет `ready to close` тем же
условием, что `close`; replan оставляет незакоммиченную работу юнита в `[~]`.
Тесты проходят на Python 3.11 (`tools/test-py311.sh`).

## Decisions         <!-- решение — почему — отвергнутая альтернатива -->
- Replan юнита с незакоммиченной работой — `[!]` → `[~]` в скилле, если
  работа остаётся в силе — повторный `prompt` юнита `[~]` дерево не
  проверяет, CLI не меняется — отвергнуто: `prompt` пропускает проверку
  чистоты для `[ ]` (теряется гарантия «изменения принадлежат юниту»).
- Python 3.11 — в Docker-образе `python:3.11-slim` скриптом
  `tools/test-py311.sh` — локально 3.11 нет, brew/pyenv не ставим —
  отвергнуто: оставить проверку `ast.parse(feature_version=(3, 11))`.
- Тесты на документах этого репозитория не ссылаются на конкретный план —
  планы закрываются и удаляются, тест ломается — отвергнуто: обновлять
  тест при каждом закрытии.

## Gotchas           <!-- ловушки, актуальные после закрытия -->
- `tools/test-py311.sh` требует запущенный Docker и ставит `git` через apt
  на каждом прогоне; репозиторий смонтирован read-only.
- Пустой `superseded_by` — ошибка `bad superseded_by ''`, не `empty`: ключ
  проверяется только по формату id, существование записи не проверяется.
