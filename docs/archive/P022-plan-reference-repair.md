## Outcome
План брошен без реализации: ни один юнит не выполнен. Задачу — прогон не
должен вставать на ссылке `Read:`/Context, которую сломал ранний юнит, —
берёт на себя авто-replan плана P025.

## Decisions
- План брошен — устаревшую ссылку чинит авто-replan P025 тем же путём, что и
  блок «нужна правка плана» — отвергнут отдельный канал `ref_updates` в
  result JSON со снимком ссылок: второй механизм правки плана ради частного
  случая.
