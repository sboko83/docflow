## Outcome

README.md написан на английском (GitHub показывает его всем посетителям),
русская версия сохранена как README.ru.md; переключение языков — ссылками
в шапке обоих файлов. Все пять скиллов `skills/` переведены на английский
вместе с описаниями-триггерами во frontmatter.

## Decisions

- README.md — английский, русский оригинал — README.ru.md, не удаление —
  GitHub рендерит README.md первым посетителям любого языка; русская
  версия нужна владельцу и русскоязычным пользователям — отвергнуто:
  оставить русский README.md (сужает аудиторию репозитория).
- Скиллы на английском, включая descriptions — скиллы ставятся в агенты
  пользователей любого проекта, набор не должен зависеть от языка
  владельца; модель матчит описание-триггер независимо от языка запроса —
  отвергнуто: русские скиллы (публичный продукт на русском).
- Внутренние доки (docs/, CHANGELOG не в счёт: он уже английский) остаются
  на русском, английский README помечает ссылки пометкой (in Russian) —
  перевод всей docs/ — отдельная задача, если понадобится — отвергнуто:
  переводить всё сразу (объём без запроса пользователей).
- Персональный пример в bsv-docflow-plan (фикстура «HLS, а не mp3»)
  заменён нейтральным («тот же формат полезной нагрузки, не удобная
  подмена») — публичный скилл не должен нести следов проектов владельца —
  отвергнуто: оставить как есть (намёк на домен владельца).
