## Outcome

`docflow run` проходит план без человека, кроме явных остановок: план
объявляет `permissions: auto|full`, `## Prerequisites` и `replan:`;
раннер проверяет предусловия и спрашивает подтверждение один раз на
старте, блок `needs plan` и устаревшую ссылку `Read:` чинит replan-агент
и продолжает, `needs human` останавливает прогон с уведомлением. Живой
прогон pi + GLM-flash: два replan (ссылка, блок) до `ready to close`.
Не проверено глазами: показ системного уведомления (`osascript` код 0).

## Decisions

- Режим прав — ключ плана плюс одно подтверждение y/N на старте; `--yes`
  пропускает, без TTY и `--yes` — код 2, ответ «n» — код 1 — коммит плана
  не снимает песочницу молча — отвергнуты ключ без подтверждения
  (эскалация коммитом) и только флаг `run` (выбор не фиксируется при
  планировании).
- Аргументы режима — таблица `permissions` профиля, слияние с
  пользовательским конфигом по ключам: claude `bypassPermissions`, codex
  `--dangerously-bypass-approvals-and-sandbox`, pi `--approve` (у pi нет
  песочницы, `full` добавляет только доверие проектным файлам) —
  отвергнуты условная правка argv по имени агента и запрет pi в `auto`.
- Триггеры авто-replan — `blocked` с `blocker: plan` и отказ `prompt` по
  ссылке; `blocker: human` и исчерпанные попытки (код 4) — стоп — провал
  `Verify` обычно ошибка кода, её чинят повторы той же сессии —
  отвергнут replan на код 4.
- Replan-агент правит только план и не коммитит; раннер проверяет HEAD,
  дерево вне плана, шапку, Goal, Constraints, Prerequisites, юниты
  `[x]`/`[-]` (байтово — docflow дописывает Handoff только в открытые),
  id, `lint`, снятие `[!]`, изменённость плана, ссылки юнита и `[ ]` над
  незакоммиченной работой; затем коммитит `Pxxx: replan Pxxx.N.M` —
  иначе следующий `prompt` отказывает снова и replan тратится на пустой
  коммит — отвергнута сходимость только лимитами.
- Провал replan на любом шаге восстанавливает текст плана до вызова —
  отвергнуто восстановление только на нарушении правил
  (полуперепланированный план в дереве).
- Правила replan самодостаточны: снятие блока и список незакоммиченных
  файлов — в промпте — у pi/codex скилла `bsv-docflow-plan` может не быть
  — отвергнута отсылка только к скиллу.
- Лимиты: 2 replan на юнит, `--replans N` (по умолчанию 3, 0 выключает)
  на прогон — отвергнуто переиспользование `--attempts`.
- P022 поглощён: устаревшую ссылку чинит тот же replan — отвергнут
  отдельный канал `ref_updates`.
- Уведомление в конце любого прогона без сигнала, включая `nothing to do`
  и провал предусловия, кроме отказа в подтверждении (ничего не
  выполнялось): darwin `osascript`, linux `notify-send`, иначе `\a` в TTY
  — отвергнуто уведомление только на `ready to close`/блоке.
- Предусловие — `- текст` или `- текст: `команда``; команды на старте до
  квоты и агентов, stdin закрыт, таймаут 60 с — провал, код 2 со строкой
  на пункт — отвергнуто различие кодов по причине провала.
- Ответ без поля `blocker` читается как `human` — старые сессии и JSON из
  текста не ломаются — отвергнуто обязательное поле для текстовых
  ответов.
- Result JSON принимается и голым объектом с `status`, которым
  заканчивается ответ — GLM-flash под pi пропускает ограждение ```json и
  сжигал попытки — отвергнут разбор любого объекта в тексте (ложные
  срабатывания на примерах кода).

## Gotchas

- `permissions: full` в файле плана снимает песочницу коммитом: держится
  только на подтверждении старта и запрете replan менять шапку.
- Правила replan живут дважды: `REPLAN_RULES` в `bin/docflow` и подраздел
  «Replan under the runner» скилла `bsv-docflow-plan` — менять вместе.
- `lint` на отсутствующий файл в `Read:` даёт предупреждение, не ошибку:
  ссылки после replan раннер проверяет только у перепланируемого юнита,
  ссылки других юнитов ловит их собственный `prompt`.
- Образец плана в скилле `bsv-docflow-plan` сверяется дословно с выводом
  dry-run в `tests/test_accept_p021.py` — правка образца требует правки
  теста.
- Тесты выключают уведомления через `DOCFLOW_NOTIFY=0` в
  `tests/helpers.py`; тест уведомления включает его со stub-командой.
