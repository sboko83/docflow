## Outcome

Go-реализация CLI (`cmd/docflow`, `internal/*`) совпадает с Python-версией:
68 паритет-сценариев, общее состояние `.docflow/` между бинарниками,
кросс-сборка darwin/amd64+arm64, linux/amd64, windows/amd64. Срез (удаление
Python, установщик) перенесён в P028. Не проверены: рантайм Linux и
Windows, живые провайдеры с квотой, разбор аргументов шире 10 ошибок
парсера и 22 справок.

## Decisions

- Модуль `bsv-docflow`, layout `cmd/docflow` + `internal/*` по слоям
  Python-файла — URL публикации не выбран, имя нейтральное — отвергнуто
  `github.com/…`: требует выбрать URL сейчас.
- `templates/` зашиты в бинарник через `embed.FS`, `skills/` читаются из
  checkout относительно бинарника — бинарник самодостаточен, а скиллы
  пользователь редактирует — отвергнуто чтение templates из checkout.
- Юнит-тесты Python стали Go-тестами пакетов, e2e-сюиты — паритет-сценариями
  против бинарника, где фикстуру продолжает противоположный бинарник —
  проверяет и вывод, и передачу состояния между версиями — отвергнуты
  изолированные проверки, не сравнивающие оба CLI.
- `tools/install.sh` собирает бинарник из checkout (`go build`), требование
  окружения — Go 1.24+ вместо Python 3.11+ — готовые бинарники отложены до
  публикации.
- Справка хранится строками Go — 22 вывода совпадают побайтно — отвергнут
  общий форматтер, менявший переносы и выравнивание.
- Перенос строк раннера — порт `textwrap.wrap(break_on_hyphens=False)`:
  ведущий отступ сохраняется, табы раскрываются до 8, слова делит только
  ASCII-пробел, длинное слово дорезается в остаток строки — иначе TTY-вывод
  расходится с Python — отвергнута собственная разбивка по
  `unicode.IsSpace`.
- `internal/format` владеет проверкой версии формата, `internal/lint` даёт
  узкие проверки для activate — без цикла импорта cycle→lint — отвергнуто
  дублирование проверок и полный lint при активации.
- lint считает бюджет через `cycle.PromptText` — совпадает с фактическим
  prompt — отвергнут отдельный расчёт размера.
- Ошибку hook отличает Git Trace2, код 4 только для hook — как в Python —
  отвергнуто считать любую ошибку commit ошибкой hook.
- `..` в путях проверяется с разделителями текущей ОС — как `Path.parts` —
  отвергнута безусловная трактовка `\` как разделителя.
- `ConfigPath` раскрывает `~имя` и без завершающего разделителя — как
  `Path.expanduser` — отвергнуто оставлять `~имя` нераскрытым.
- TTY: интерфейс `IsTerminal()` для тестовых писателей и termios ioctl на
  Darwin/Linux; Windows `pidAlive` — `OpenProcess` +
  `WaitForSingleObject` — без внешних зависимостей и с рабочим lock —
  отвергнуты TTY-библиотека и заглушка `pidAlive`.
- Суммы контекста — `math/big` с `json.UseNumber` — точность целых как в
  Python — отвергнуты fixed-width и float64.
- Срез перенесён в P028 под Go-раннер (`bin/docflow-go run`): он вызывает
  шаги цикла через `os.Executable()`, удаление `bin/docflow` его не
  задевает — отвергнут интерактивный срез, исходно задуманный потому, что
  Python-раннер вызывает себя как `python3 bin/docflow`.

## Gotchas

- `templates/` зашиты в бинарник: правка шаблона без
  `go build -o bin/docflow ./cmd/docflow` не видна CLI.
- Скиллы и строка `--version` ищутся относительно бинарника после
  разрешения symlink: бинарник, скопированный из checkout, их теряет.
- Раннер вызывает `verify`/`commit` через `os.Executable()`. `go build -o`
  заменяет файл новым inode, поэтому пересборка во время прогона безопасна;
  запись поверх файла (`cp`) — нет.
- Имена файлов с не-UTF-8 байтами Go обрабатывает как байты; на macOS такой
  файл не создать (EILSEQ) — тест возможен только на Linux.
