## Outcome           <!-- 2–3 строки: что теперь есть -->

Правка ростера ушла из ручного TOML в браузер: `docflow roster web`
поднимает локальный редактор (доступы с маршрутами «усилие → класс»,
роли, варианты, пикеры из каталога скана) и атомарно пишет `roster.toml`
и файлы вариантов. Класс модели закреплён за парой «модель + усилие»:
политика v3 с таблицей `[route]` заменяет `[model]` и `[effort]`,
`roster migrate` ведёт v1 и v2 сразу в v3, бриф и цепочки печатают
`access/model@effort`. Проверено юнит-тестами, приёмочным сценарием на
копии живой политики (`tools/accept-roster-web.sh`) и рендером в
браузере; `docflow tui` не тронут и читает те же файлы.

## Decisions         <!-- решение — почему — отвергнутая альтернатива -->
- `[route."ACCESS/MODEL"]` с парами `"усилие" = "класс"` заменяет `[model]`
  (класс) и `[effort]` (пин усилия) — класс принадлежит паре модель+усилие,
  одна модель может быть cheap на low и standard на high; два старых ключа
  удаляются из разбора. Отвергнуто: оставить `[model]`/`[effort]` рядом с
  `[route]` — три способа выразить одно, freeze-правило требует замены.
- Политика версии 2 → 3; v1- и v2-файл любой командой — код 2 с подсказкой
  `docflow roster migrate`, миграция идёт цепочкой v1→v3 с `.bak`.
- Ключ маршрута при миграции: пин усилия из `[effort]`; модели с классом
  `[model]` без пина — реальное усилие, дающее этот класс, `-` — только
  для явного пина `-`, иначе reasoning-модель молча теряет усилие при
  миграции. Класс — из `[model]`, а без записи — автоматический класс по
  имени модели в резолвере (в файле не пишется, `auto` — не значение
  формата). Отвергнуто: `-` для отсутствующего пина — теряется усилие.
- `roster web` — новая подкоманда CLI — обобщает существующие способы правки
  политики: ручное редактирование `roster.toml` и машинную запись вариантов
  из TUI (`SaveVariants`). TUI остаётся читателем (решение пользователя
  2026-11-07: «tui пока не трогаем»).
- `roster.toml` становится машинно-записываемым: `SavePolicy` пишет файл
  целиком (атомарно, через временный файл с перечитыванием парсером — как
  `SaveVariants`); комментарии в файле не сохраняются, ручная правка
  возможна, но следующий Save её перепишет. Отвергнуто: патчевая запись с
  сохранением комментариев — TOML round-trip без зависимостей хрупок.

## Gotchas           <!-- ловушки, актуальные после закрытия -->

- Пикеры редактора и кнопка «+ уровень» берут уровни ризонинга из каталога
  скана; с пустым каталогом редактор показывает только содержимое файлов
  (усилие — текстом), матрица ролей повторяет бриф («no route»), баннер
  предлагает `docflow roster scan`. Данные при этом не искажаются:
  операции пишут реальные ключи маршрутов.
